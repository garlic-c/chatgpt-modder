# Windows 使用说明

Windows 版已由用户确认可用，当前适配 ChatGPT 26.1027.30824。

1. 打开修改器，等待自动定位；应用前完全退出 ChatGPT。
2. 启用所需模块并应用。商店版会创建用户目录副本，补丁只写入该副本。
3. 从桌面的 **ChatGPT（Modder）** 快捷方式启动。原快捷方式仍对应官方版。
4. 停用时先退出副本，在修改器中恢复原版。

副本通常位于 `%APPDATA%/ChatGPT Modder/clients/`，备份位于相邻的 backups 目录。修改器不接管 WindowsApps 权限、不更改官方安装、不自动拷贝凭据；副本可能需要重新登录。

副本不会跟随商店自动更新。官方更新后重新打开修改器核对适配版本，再准备对应副本；不要用旧备份覆盖新版本。恢复只恢复程序文件，不是账号资料恢复或卸载工具。

修改器关闭后补丁仍有效，无需常驻。出现故障时导出兼容诊断，并保留备份和事务记录；不要上传凭据、Cookie、聊天数据库或整个用户配置目录。
