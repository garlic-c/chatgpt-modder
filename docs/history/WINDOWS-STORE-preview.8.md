# Windows 商店版适配原型 — preview.8

## 使用

1. 运行 Windows preview.8，应用自动通过当前用户的 Get-AppxPackage 及包清单定位程序目录，无需在文件选择器中进入 WindowsApps。
2. 完全退出 ChatGPT。确认版本及文件指纹兼容后，打开功能开关并点击“应用修改”。
3. 首次应用会将安装资源复制到 `%APPDATA%\ChatGPT Modder\clients\<来源指纹>\client`，验证复制一致性，再通过既有事务引擎备份及打补丁。
4. 从桌面的 **ChatGPT（Modder）** 快捷方式启动副本。原开始菜单、固定任务栏及商店快捷方式仍启动官方安装，因此其中不会显示补丁效果。
5. 需要停用时在 Modder 中恢复原版；此操作恢复本地副本，不触碰 WindowsApps。官方安装始终可通过原快捷方式运行。

## 行为与边界

- 不取得 WindowsApps 所有权，不修改 ACL，不替换官方商店包，不需要管理员权限。
- 仅复制安装文件；不会自动复制账号、Cookie、密钥或会话目录。副本可能需要重新登录。
- 不注册虚假的 MSIX 身份。副本脱离商店包身份运行；启动、登录、OAuth 回调、通知及所需系统组件是否完整可用，必须在用户 Windows PC 上验证，不能仅凭文件复制成功宣称支持。
- 只有既有适配器匹配版本及共享 UI 文件指纹时才开放修改；其他版本仍需导出兼容诊断适配。
- 重复应用复用同一来源指纹的副本和备份。官方更新后，自动定位新包并重新检查；不会自动给新版本套旧补丁、用旧备份覆盖新客户端或在新包不兼容时偷偷选回旧副本。新旧副本分目录保留。
- 副本不跟随商店自动更新。官方更新后需重新打开 Modder 检查并明确应用，桌面快捷方式才会指向新副本。
- 创建副本失败时清理暂存资源，原商店安装不变。补丁失败时由原事务引擎回滚；桌面快捷方式只能在补丁成功后创建。
- 旧副本与备份不会自动删除，避免丢失恢复依据；本版没有副本清理功能。
- 修改器仍在关闭最后一个窗口后退出，无后台服务或托盘。

## 已验证

在 macOS 构建主机上通过 TypeScript 类型检查、38 项自动化测试、Windows PE 图标资源检查和打包检查。新增测试覆盖路径解析、来源保持不变、重复准备、版本隔离、失败清理及符号链接拒绝。PowerShell 实际发现、受保护目录的读取权限、Windows 复制属性、快捷方式创建、客户端启动及登录仍待用户实机验证。
