# ChatGPT Modder

可扩展、无需后台常驻的 ChatGPT 桌面修改器。Electron＋TypeScript，首个模块为头像上方的额度显示。

**当前 Windows 测试包是 0.1.0-preview.8，macOS 安装包仍为 preview.7；这是实验预览，不是已通过双平台验收的正式版本。** 未修改本机正在使用的 ChatGPT。Windows 实机验收由用户在另一台 PC 上进行。

## preview.8 Windows 商店版原型

自动读取商店包清单定位程序，无需手动选择 WindowsApps。兼容版本可创建用户目录可修改副本，补丁成功后生成“ChatGPT（Modder）”桌面快捷方式。官方安装保持不变。此流程的 Windows 启动与登录仍待实机验证，详见 [使用与限制](WINDOWS-STORE-preview.8.md)。

## preview.7 图标与 DMG

- macOS 和 Windows 使用批准的 Tibo 分尺寸图标。
- macOS 提供带自定义背景的 DMG：打开后将 ChatGPT Modder 拖到 Applications。
- DMG 使用 768×592 布局与 Retina 背景，背景原文件保留于 build/dmg/background-source.png。
- 本机完成 DMG 校验、挂载、Finder 布局元数据及复制一致性检查；桌面自动化连接不可用，未完成挂载窗口截图验收。
- 重建：`npm run pack:dmg`；同时构建 DMG 和 ZIP：`npm run pack:mac`。

## preview.6 布局与日志

- 默认窗口进一步收窄为 500×440，开关位于功能名下方。
- 右侧局部预览等比缩小并完整显示，说明文字合并为一行。
- 底部空白处保留为运行日志区，只显示最新 3 条，不提供滚动历史。
- 本轮只改变修改器界面，不需要重新应用 ChatGPT 补丁。

## preview.5 窄版与状态同步

- 窗口默认 520×460，预览位于项目右侧，只显示侧栏左下角；示意百分比 42%，对话列表使用抽象粗线条，头像为“你”。
- 客户端按钮文案为“已定位”，仍可点击更换路径。
- 启动检测后，功能开关与已安装模块状态同步；恢复原版后关闭，重新应用后开启。未定位或无法安全操作客户端时禁用开关。
- 静态界面文字不可选中；文本输入控件仍可正常选取文本。

## preview.4 界面与自动检测

- 启动时检测记住的位置和系统常见安装位置；Windows 同时查询官方商店包位置。默认无需选择客户端，标题右侧显示实际 ChatGPT 图标及“已安装”，可点击更换路径。商店目录的写入保护仍保持不变。
- 取消左栏，使用与窗口融为一体的标题栏；开关放在功能名称右侧，按当前窄侧栏重画用量及“你”头像预览。
- 版本号移至底部，正常检测结果不再显示实验阶段声明；错误、版本不匹配和写入保护仍明确提示。
- 5H 剩余百分比为 10% 或更低时变红；无数据不变红。额度模块为 1.0.3。

## preview.3 视觉调整

额度区域跟随实际头像中心对齐，侧栏展开、收起及尺寸变化时重新定位。倒计时单位改为小写（如 `2h35m`），周进度条厚度为 1px，长度与倒计时文字等宽。字号保持不变：百分比 12px；展开倒计时 11px，收起 9px。

## preview.2 修正

旧版额度组件读取异步状态时，等待可能冒泡到宿主的整页加载边界，造成持续“初始化”。本版为额度组件加入独立的加载边界：等待期间仅显示额度占位，不阻塞原有头像和主界面；数据到达后自动显示。

使用新版选择同一客户端后可直接重新应用，程序会从原版备份重建。若希望先恢复正常使用，也可以先点击“恢复原版”。保留现有备份，不需要删除账号或聊天数据。

这是针对已复现挂起机制的修正；用户设备上报告的完整场景仍需复测，未据此将兼容状态改为正式支持。

## 使用

1. 打开对应平台的修改器。macOS 打开 `.dmg` 后将应用拖到 Applications（也可解压 ZIP 后运行 `.app`）；Windows 运行便携 `.exe`。
2. 应用自动检测客户端；右上角显示“已定位”后可直接操作。如果没有找到，点击“选择客户端”。也可点击“已定位”更换位置。
3. 选择需要启用的功能模块。
4. **完全退出目标 ChatGPT**，再点击“应用修改”。修改器不会强制终止客户端。
5. 完成后重新启动 ChatGPT，可以直接关闭修改器。
6. 停用所有模块或点击“恢复原版”会恢复同一版本的原始应用。异常中断后先点击“恢复中断操作”。

本预览包尚未使用公开发行证书签名或完成 Apple 公证。发布到公开渠道前，仍需完成发行签名和双平台验收。不要通过关闭系统整体安全保护来运行它。

## 额度显示

从上到下：5H 剩余百分比、距 5H 重置的倒计时、周剩余额度细条。悬停进度条显示周剩余百分比。

复用客户端当前账号的额度状态，不采集密码、不要求 API 密钥、不运行独立采集服务。数据缺失、出错、账号不匹配或窗口已过期时显示占位；到期请求刷新，不自行假定额度恢复。计时器随组件卸载清理。

## macOS 首次启动停在初始化

本地重签名后，macOS 可能要求重新授权访问 `Codex Storage Key`。系统授权窗口可能在主窗口后面，客户端此时会一直等待 cookie 服务，看起来像初始化卡住。请在 macOS 系统提示中完成授权；密码只输入系统窗口，不发送给修改器或聊天。可能有多个连续提示，需要逐个处理。

不要删除钥匙串项目、清空 cookie 或关闭加密来解决该问题。之后重新应用不同补丁、改变本地签名时，系统可能再次要求授权。2026-10-30 用户现场已确认：完成系统授权后，原有登录状态和真实额度显示恢复；没有因此更换补丁版本。

开发验证的配置目录隔离不等于系统钥匙串隔离。今后的自动启动测试必须同时隔离系统凭据存储，不能让临时签名测试副本创建或请求生产钥匙串项目。

## 已知限制

- macOS 必须更新 ASAR、Info.plist 和框架摘要，并重新签名辅助进程、框架和主程序。ASAR 校验保持启用。
- 本地签名不能保留 OpenAI 专属团队授权、共享钥匙串组和应用组授权；为加载现有框架，修改后的进程使用局部的库验证例外。**登录保持、通知、自动化权限、电脑使用和官方更新行为尚未完整验收。** 需要先在副本上测试；恢复原版可恢复备份中的签名和内容。
- Windows 更新 PE 完整性资源会改变原有可执行文件签名；商店安装包还有系统级保护，本预览不处理这类安装。
- 不能保证修改后仍可直接安装官方增量更新。建议先恢复原版，再更新客户端；更新后重新检查兼容性。
- 如果官方更新或其他程序已改变客户端，旧备份不会覆盖新版；需要重新安装官方版本或另行适配。
- 备份是整个应用目录，需预留原版备份和暂存副本所需空间。备份保留在修改器的数据目录，不包含 ChatGPT 的聊天数据目录。
- 修改器关闭最后一个窗口即退出。只有写入过程中会阻止关闭，以免中断替换；不创建托盘、服务、计划任务或开机启动项。

## 开发与构建

使用 Node.js 22.12 或更新版本；推荐 Node.js 24 LTS。首次安装需要联网下载 Electron 和打包工具。

```sh
npm ci
npm run typecheck
npm test
npm start
npm run pack:mac
npm run pack:win
```

macOS 打包默认 arm64，Windows 打包默认 x64；Windows ARM64 的运行与发行包尚未验收。

命令行用于开发诊断，也受同样的版本、指纹和进程检查约束：

```sh
node --import tsx src/cli.ts inspect "/path/to/ChatGPT.app"
node --import tsx src/cli.ts diagnose "/path/to/ChatGPT.app"
```

详细说明见 [扩展开发](docs/ARCHITECTURE.md)、[Windows 测试清单](docs/WINDOWS-TEST.md) 和 [验证记录](docs/VALIDATION.md)。
