# Windows PC 测试

测试包：`ChatGPT Modder-0.1.0-preview.2-win-x64.exe`，x64 便携版。当前未通过 Windows 实机验收。

## 第一轮：检测与退出

1. 打开修改器，确认文字、功能开关和按钮显示正常。
2. 选择 ChatGPT 安装目录，即包含 `ChatGPT.exe` 或 `Codex.exe` 以及 `resources` 的文件夹。
3. 记录客户端版本、兼容状态和提示内容。若目录无法访问，保留错误文字即可。
4. 点击“导出兼容诊断”，保存 JSON。内容仅为安装资源的版本和指纹。
5. 关闭修改器，在任务管理器确认修改器及其辅助进程全部退出。

如果是 `WindowsApps` 下的商店版或存在 MSIX 清单，当前会禁止应用补丁。这是已知限制，**不要修改目录权限、禁用系统校验或强行写入**。先反馈安装类型和诊断结果，后续需要专门解决包身份与安装方式问题。

如果版本或界面文件指纹不匹配，也会禁止修改。先返回诊断文件，以便针对该构建补齐适配；不要更改程序中的版本限制。

## 第二轮：仅适用于成功匹配的非商店目录

在有可恢复官方安装来源的测试环境进行：

1. ChatGPT 保持运行时点击应用，应提示先完全退出，目标不应被修改。
2. 完全退出 ChatGPT，启用额度模块，应用修改。记录完整操作日志。
3. 关闭修改器，再启动 ChatGPT。检查是否正常启动、是否需要重新登录。
4. 登录后检查头像上方的两行文字和周剩余额度细条；与客户端原有额度页面核对。
5. 悬停进度条核对具体周剩余百分比；测试深浅主题、窄侧栏和展开侧栏、多个窗口。
6. 重启 ChatGPT 和重复应用补丁，确认没有重复组件。
7. 检查断网、恢复网络、休眠唤醒及切换账号；旧账号额度不能残留。
8. 关闭 ChatGPT，在修改器点击恢复原版。重新启动确认功能消失、原有功能正常。
9. 再次启用，确认可重复安装和恢复。
10. 官方更新前先恢复原版。更新后检查未知版本是否禁止直接套用旧补丁。

不需要为了测试刻意耗尽额度、购买重置或触发大量模型请求。
