# ChatGPT Modder 0.1.0-preview.13

新增 Linux 支持（实验），三端适配的 ChatGPT 版本均为 26.1027.30824。

- Linux：识别官方 `.deb` 安装（`/usr/lib/chatgpt`），指纹与额度模块绑定全部取自该官方包的资源逐项核对，未从 macOS/Windows 构建推测。
- 系统安装保持不变：应用时在用户目录创建本地副本，并在应用菜单写入 **ChatGPT（Modder）** 启动项；官方启动方式仍打开原版。副本不随 `.deb` 自动更新，官方版本变化时按既有升级衔接规则为新版独立备份。
- Linux 发行包为 x64 AppImage，未签名。
- 已在 Ubuntu 24.04 上用真实客户端副本验证：识别与指纹匹配、应用与归档完整性校验、修改版客户端启动、原样恢复均通过；登录状态下额度组件的显示尚待实际使用确认，因此 Linux 适配标记为实验。
- 注意：客户端每次启动会在自身目录创建空的 `extensions/` 文件夹（原版亦然）。恢复前若被提示客户端已变化，请退出 ChatGPT 后删除副本中这个空文件夹再恢复。详见 [Linux 使用说明](../LINUX-OPERATION-AND-RISKS.md)。

macOS 与 Windows 的行为不变。
