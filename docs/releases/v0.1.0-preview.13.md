# ChatGPT Modder 0.1.0-preview.13

本版为源码更新，Release 仍只提供 macOS 与 Windows 包，适配的 ChatGPT 版本均为 26.1027.30824。

- 源码新增 Linux 实验适配：识别官方 `.deb` 安装（`/usr/lib/chatgpt`），指纹与额度模块绑定全部取自该官方包的资源逐项核对，引擎流程已在 Ubuntu 24.04 上用真实客户端副本验证（识别、应用、完整性校验、启动、原样恢复）。
- **不提供 Linux 发行包**：ChatGPT 的 Linux 客户端界面布局与 macOS/Windows 不同，额度组件在登录后的实际显示效果未经真机确认。需要 Linux 版的用户可克隆仓库自行改造编译（`npm run pack:linux`），详见 [Linux 使用说明](../LINUX-OPERATION-AND-RISKS.md)。
- 修复 Linux 副本测试在 Windows 上的权限断言（按平台跳过，与既有 macOS/Windows 副本测试的写法一致）。

macOS 与 Windows 的行为不变。
