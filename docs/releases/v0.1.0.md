# ChatGPT Modder 0.1.0

首个正式版，以 Windows 测试版 test.4 为基线。macOS Apple Silicon 使用 DMG，Windows x64 使用便携 EXE。下载包内仅包含修改器。

- 在 ChatGPT 26.1027.30824 的侧栏头像上方查看 5 小时剩余额度、重置倒计时和每周额度进度条。
- Windows 新建的商店客户端副本和备份存放在 LocalAppData。修改器仍能读取 Roaming 中已有的恢复记录。
- 恢复后可核对本次副本和备份的路径与合计大小，自行决定保留文件或移入回收站。下次从开始菜单启动官方 ChatGPT。
- Windows 客户端检测会跳过辅助运行时，优先显示成功读取的客户端。

ChatGPT 26.1120.50957 支持定位和兼容诊断，此版本的额度补丁尚未开放。Microsoft Store 对应的包版本为 26.1120.6357.0。

安装包未使用公开发行证书签名或 Apple 公证。下载后可使用随附的 SHA256SUMS.txt 核对文件。详见 [Windows 使用说明](../WINDOWS-OPERATION-AND-RISKS.md)。
