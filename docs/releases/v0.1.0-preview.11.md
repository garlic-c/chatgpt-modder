# ChatGPT Modder 0.1.0-preview.11

## 更新

- macOS 适配本机更新后的 ChatGPT **26.1027.30824**，与 Windows 当前适配版本一致；分别锁定两平台的资源指纹和原生文件，保留版本校验。
- 修改器两平台统一推进至 preview.11，避免覆盖已发布的 preview.10。
- 修复 macOS 复制框架符号链接时权限位变化导致的备份校验失败，保留精确校验与恢复。
- DMG 底部改用原毯面纹理的生成式扩展，不再填纯色色块；在此前基础上再向下扩 10pt，窗口变为 **768×602**。原人物、文字与图标位置保持。
- 按用户确认更新双平台可用状态，关闭历史待确认问题，精简说明；历史排查资料归档保留。
