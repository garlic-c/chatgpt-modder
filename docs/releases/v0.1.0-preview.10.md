本次为首个 GitHub Release，标记 **Pre-release**，仓库及下载保持私密。安装包未配置公开发行签名或 Apple 公证，不代表 OpenAI 官方发布。

## 下载与使用

| 平台 | 文件 | 使用 |
| --- | --- | --- |
| macOS Apple Silicon（arm64） | ChatGPT Modder-0.1.0-preview.10-mac-arm64.dmg | 打开 DMG，将应用拖到 Applications；既有安装先退出再替换 |
| Windows x64 | ChatGPT Modder-0.1.0-preview.10-win-x64.exe | 运行便携 EXE；修改前完全退出目标客户端 |

macOS 延续已确认的 Tibo 图标及 DMG 背景，窗口 768×592，底部 80pt 留白，应用与 Applications 图标位于 y=180，拖拽箭头同步上移。安装包基于当前同步源码重新构建，格式与布局沿用预设，并非将旧 preview.7 二进制改名。

Windows 为商店安装创建用户目录可修改副本，官方 WindowsApps 安装及其快捷方式不变；修改后从“ChatGPT（Modder）”快捷方式启动副本。副本可能需要重新登录，不自动复制凭据或会话目录。副本不会跟随商店自动更新。

## 本版内容

- 头像上方的 5H 剩余额度、重置倒计时和 1px 周进度条；不超过 10% 时百分比红色。
- 两平台使用同套分尺寸 Tibo 图标；Mac 深浅主题与局部侧栏预览。
- Windows 修复 PE 完整性资源解析中的算法大小写及路径分隔符问题，保留完整性校验。
- Windows 26.1027.30824 增加固定 ASAR/UI 资源指纹与版本专用绑定，仍标为 experimental。
- README 新增用户提供的修改器与低额度实机截图；界面截图来自 macOS preview.7，仅为功能示例。

发行流程先在 macOS 与 Windows 分别执行锁定安装、类型检查、测试与构建；macOS 验证 DMG 校验，Windows 检查启动器及内部程序七档图标。两端产物准备齐全后，生成校验清单和构建信息，再一次发布，不发布缺少任一平台附件的半成品。

这是安装资源与自动化验证，不是 Windows 普通启动或新安装 Mac 的人工验收。没有把官方客户端、账号资料、调试副本或备份包含在发布物中。
