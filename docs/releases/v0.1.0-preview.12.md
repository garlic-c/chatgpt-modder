# ChatGPT Modder 0.1.0-preview.12

修复 ChatGPT 官方更新后提示“客户端发生变化，拒绝覆盖或旧版恢复”的问题。

旧版备份记录不会删除。当前客户端通过已知版本、ASAR、界面及原生文件指纹检查后，用户重新应用时会为新版建立独立备份，再从新版原件构建补丁。

- 保留旧版记录，不用旧备份覆盖新客户端。
- 恢复操作只针对当前版本对应的备份。
- 未知版本、指纹不符、同版本文件被外部改动时继续拒绝修改。
- 新备份建立中断后可恢复，原有备份不受影响。

两平台继续适配 ChatGPT 26.1027.30824，DMG 保持 preview.11 的纹理扩展及 768×602 布局。

更新修改器后，完全退出 ChatGPT，启用模块并重新应用即可，无需手工删除备份。
